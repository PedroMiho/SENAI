# SENAI — Materiais de Cursos de Tecnologia da Informação

Este repositório reúne materiais didáticos, exemplos de código, exercícios, laboratórios e projetos utilizados nos cursos de Tecnologia da Informação ministrados pelo professor **Pedro Henrique Miho de Souza** no SENAI.

Os conteúdos foram desenvolvidos para apoiar as atividades práticas realizadas em sala de aula e permitir que os alunos revisem os assuntos estudados.

## Objetivo

Disponibilizar materiais de apoio para cursos relacionados à programação, desenvolvimento web, inteligência artificial, Java, Python, banco de dados e desenvolvimento de aplicações.

O repositório também mantém um histórico dos exemplos, desafios e projetos desenvolvidos durante as aulas.

## Conteúdos disponíveis

## Como utilizar os materiais

1. Localize a pasta correspondente ao curso.
2. Selecione a aula ou o assunto desejado.
3. Leia as instruções e os comentários presentes no código.
4. Execute os exemplos durante a aula.
5. Utilize os desafios para praticar os conceitos apresentados.

Para baixar todo o repositório:

```bash
git clone https://github.com/PedroMiho/SENAI.git
```

Depois, acesse a pasta:

```bash
cd SENAI
```

## Execução dos projetos

### Projetos HTML, CSS e JavaScript

Os projetos front-end podem ser abertos diretamente no navegador ou executados com uma extensão de servidor local, como o Live Server.

### Projetos Python

Verifique se o Python está instalado:

```bash
python --version
```

Para executar um arquivo:

```bash
python nome_do_arquivo.py
```

### Projetos Java

Verifique se o Java está instalado:

```bash
java --version
```

Projetos simples podem ser executados diretamente pela IDE utilizada nas aulas.

### Projetos Maven e Spring Boot

Quando existir um arquivo `pom.xml`, verifique se o Maven está disponível:

```bash
mvn --version
```

Para executar uma aplicação Spring Boot:

```bash
mvn spring-boot:run
```

### Projetos com banco de dados

Alguns projetos utilizam MySQL e podem exigir:

- criação prévia do banco de dados;
- execução dos scripts SQL;
- configuração da URL de conexão;
- definição de usuário e senha por variáveis de ambiente.

Não publique credenciais reais no repositório.
